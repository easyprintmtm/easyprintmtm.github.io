**A simple, responsive and bilingual machine rental booking website for
EasyPrint.**

🌐 **Live Website:** https://easyprintmtm.github.io/

------------------------------------------------------------------------

## 📌 About the Project

EasyPrint is a copier and Xerox machine rental service booking website
designed to make machine rental enquiries simple and convenient.

Customers can explore available Black & White and Colour copier rental
plans, select their intended usage, enter their details, and send their
booking enquiry directly through WhatsApp.

The website supports both **English and Telugu**, providing an easy
experience for customers.

## ✨ Features

-   **Bilingual Interface:** Switch between English and Telugu.
-   **Machine Selection:** Choose between Black & White and Colour
    machines.
-   **Automatic Rental Plans:** Displays the relevant rental plan based
    on the selected machine.
-   **Plan Details:** Shows monthly rental charges, free copy limits and
    additional copy rates.
-   **Purpose Selection:** Customers can select their intended machine
    usage.
-   **Customer Name:** Optional customer name field.
-   **Location Details:** Customers can enter their location.
-   **WhatsApp Integration:** Prepares a structured enquiry message with
    the selected details.
-   **Responsive Design:** Designed for desktop, tablet and mobile
    devices.
-   **User-Friendly Interface:** Modern layout, attractive buttons,
    animations and easy navigation.

## 📝 Booking Process

1.  Select Machine Type -- Black & White or Colour.
2.  View the corresponding rental plan automatically.
3.  Select the Purpose of the machine.
4.  Enter Customer Name (optional).
5.  Enter Location.
6.  Submit the enquiry through WhatsApp.

## 💬 WhatsApp Enquiry Format

The website prepares a structured WhatsApp message containing:

-   Machine Type
-   Selected Rental Plan Details
-   Purpose
-   Customer Name (if provided)
-   Location

Question labels are formatted in bold to make the enquiry easier to
read. The customer reviews and sends the prepared message in WhatsApp.

## 🌍 Language Support

The website supports:

-   English
-   తెలుగు (Telugu)

The selected language controls the form labels, options and WhatsApp
enquiry message.

## 🚀 Run Locally

1.  Clone the repository:

    ``` bash
    git clone https://github.com/easyprintmtm/easyprintmtm.github.io.git
    ```

2.  Open the project folder.

3.  Open `index.html` in your web browser.

No backend server is required for the static website.

## 🌐 GitHub Pages Deployment

This project is intended to be hosted using GitHub Pages.

1.  Upload the website files to the repository.
2.  Ensure the main webpage is named `index.html`.
3.  Open repository **Settings → Pages**.
4.  Select the deployment branch and root folder.
5.  Save and wait for GitHub Pages to publish the changes.

Live website: https://easyprintmtm.github.io/
